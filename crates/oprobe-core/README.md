# oprobe-core

**Internal.** This crate is the engine of the [oprobe](https://github.com/hxddh/oprobe) binary:
the operator spec, workloads, the profile and its findings, `prove`, the run store and the lab.
It is not published to crates.io and has **no semver promise**: any release may change any item.

- To profile your own OpenDAL operator, use [`oprobe-trace`](https://github.com/hxddh/oprobe/blob/main/docs/embedding.md).
- To use oprobe, install the binary: see [install](https://github.com/hxddh/oprobe/blob/main/docs/install.md).
