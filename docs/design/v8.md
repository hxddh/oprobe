# oprobe 8.0 — True Wire & Layer Parity

Status: active specification for `v8.0.0`. Builds on [`v6.md`](v6.md) (product boundaries),
[`v7-review.md`](v7-review.md) (`oprobe.trace/7` operations), and [`app-native.md`](app-native.md)
(the `nsh` workbench).

---

## 1. Positioning & Non-Goals

`oprobe` stays strictly within its v6 boundaries:

- **One workbench (`oprobe`) · One layer (`oprobe-trace`) · One file (`.oprobe`).**
- **Four CLI commands:** `run`, `prove`, `show`, `lab` (plus `demo` and bare `oprobe` for the app).
- **Loop:** **Profile → Explain → Prove.**
- **Explicit non-goals:** no monitoring daemon (`watch`), no CI regression gate, no cloud cost
  calculator, no non-OpenDAL SDK benchmark harness, no HTML/CSV/Markdown exporter, and zero
  business logic in `crates/oprobe/src/ui/`.

### Why 8.0

In `7.0–7.2`, production traces (`oprobe.trace/7`) gained per-call operation rows, yet still
diverged semantically from `oprobe run` (`oprobe.run/6`):

1. High-level OpenDAL `Reader` (concurrent chunking, `fetch` range coalescing) and multipart
   `Writer` execute above `raw::Service`, splitting one logical operation into independent raw
   calls or hiding `"multipart"` verbs unless wrapped in manual `OpScope`s.
2. `TraceContextLayer` replaced `OperationContext::http_transport`, clobbering
   `ConcurrentLimitLayer::with_http_concurrent_limit` (or losing HTTP semaphore `queue_us` if
   ordered inside).
3. Schema fields for cache activity (`cache_lookups`, `cache_hits`, `cache_hit_bytes`,
   `cache_lookup_us`), HTTP/2 stream multiplexing (`streams_count`, `stream_wait_us`,
   `flow_stall_us`), and kernel send-buffer drain (`send_buffered_us`, `upload_acked_us`) were
   defined in `oprobe-trace` but never populated.
4. Concurrent HTTP/2 streams on a newly dialed connection raced on `Sock::Unknown`, scanning
   `/proc/self/fd` multiple times and multiplying kernel `wire_rx_bytes` / `wire_tx_bytes`.

`oprobe 8.0` bumps the embedded trace format to **`oprobe.trace/8`** (while reading `oprobe.run/6`,
`oprobe.trace/6`, and `oprobe.trace/7` transparently) to deliver **100 % wire and layer parity**
between embedded production traces and `oprobe run`, alongside verified bug fixes, richer storage
observability, zero-friction CLI workflows, and native desktop/TUI polish.

## 2. Pillar I — Verified Bug Fixes & Codegen Gate

### Engine, Trace & Prove
1. **Production `slow_multipart` and `small_ranges` parity:** record multipart writes (`UploadPart` /
   `CreateMultipartUpload` / `CompleteMultipartUpload` or multi-request writes) and coalesce logical
   `Reader` chunk/range streams so both findings fire identically on `oprobe.trace/8` and
   `oprobe run`; make `OpKind::Write` in `oprobe run` honour `spec.write.{chunk, concurrent}`.
2. **`small_ranges` remedy ordering & `read.gap` baseline:** distinguish multi-range coalescing
   (`read.gap`) from single-stream chunk concurrency (`read.concurrent`) without shadowing, and
   start `prove` sizing of `read.gap` above OpenDAL 0.59's `1 MiB` `merge_ranges` default (`2 MiB`,
   domain `4 KiB .. 32 MiB`) rather than shrinking it to `256 KiB`.
3. **Composable `TraceContextLayer`:** wrap any existing `HttpTransporter` on `OperationContext` as
   an outer queue-timing / inner wire-timing sandwich (or preserve semaphore permits around
   `FidelityTransport`) so `ConcurrentLimitLayer::with_http_concurrent_limit` works in either layer
   order and records exact `queue_us`.
4. **Race-free per-connection `TcpProbe` & bounded LRU:** bind socket FDs/handles once per physical
   connection without concurrent `Sock::Unknown` duplication, and evict idle connections by LRU
   without resetting baseline counters of active connections.
5. **Honest cancellation, tail-cut & mid-stream retry accounting:**
   - Pre-header cancellations (`CancelGuard`) record unknown/preserved connection state instead of
     fabricating `Protocol::Http1` + `reused: false`.
   - Mid-body stream drops mark the request as incomplete/aborted rather than `200 OK`.
   - Mid-stream `RetryLayer` range continuations (`"read.full"` -> `"read.range"`) link cleanly to
     their parked parent operation.
6. **Compilable OpenDAL 0.59 `to_rust`:** translate alias schemes (`gs`, `r2`, `minio`, `lab`, …)
   to canonical OpenDAL schemes (`gcs`, `s3`, …), pass `[options]` via `Operator::via_iter` /
   `(uri, options)` instead of comments, and emit explicit imports when `ReqwestTransport` is used;
   enforce with a compile-checked test.
7. **`prove` on non-provable findings:** refuse `oprobe prove <RUN> bandwidth_cap` cleanly on
   read-only workloads where `ThrottleLayer` is a no-op, with a clear `--with` hint.
8. **`LabServer` HTTP/2 & CLI parity:** omit `connection: close` on HTTP/2+ responses (RFC 9113
   §8.2.2), deduplicate `CommonPrefixes` across paginated `ListObjects` boundaries, and expose
   `--allow-remote` and `--max-store-size` on `oprobe lab`.
9. **Store & `RunFileWriter` hygiene:** append `.tmp` instead of replacing extensions in
   `RunFileWriter`, support ID prefix / `last` lookup for `oprobe show <PROVE>`, and clean up
   associated `.prove.json` files when deleting a parent run.

### Native App & Terminal TUI
1. **System & SSH clipboard in TUI:** wire an OSC-52 + OS command (`pbcopy` / `wl-copy` / `xclip` /
   `clip.exe`) `ClipboardBackend` in `term.rs`.
2. **Prove job isolation:** tag running `prove_job`s with `origin_run_id`, cancel or scope results
   cleanly across run switches, and guard `Save to op.toml` against cross-run writes.
3. **Immutable `Proved` objective:** store `objective` on `jobs::Proved` / `ProveOutput` so toggling
   `Goodput` / `p99` after completion never corrupts rendered units.
4. **Smooth `layers.concurrent_limit` switch:** seed default `http = 32` (or keep draft UI state)
   when toggling `concurrent_limit` ON so the switch never snaps back to OFF.
5. **Safe, faithful `Run Again`:** preserve the run's full `OperatorSpec` and workload parameters,
   route network write runs through `App::plan` confirmation, and keep `s.form` decoupled from the
   active job's sidebar label.
6. **Paths with spaces:** quote-aware parsing in `New Run` so `op.toml` paths chosen via native file
   dialogs work when directories contain spaces.
7. **Horizontal scroll in `Compare`:** wrap wide comparison tables in horizontal scroll containers.
8. **Stored proves & richer file open:** load `RunList.proves` in the app, persist prove state across
   run selection, and open `.prove.json` and `op.toml` via file open / drag-and-drop.
9. **Reactive `i18n`, quiet menus & accurate scheme classification:** reactive `Lang` signal without
   unmounting `shell()`, explicit `Lang` propagation to worker threads, state-transition-only OS
   menu updates, and target-aware error classification instead of hardcoded `"s3"`.

## 3. Pillar II — Rich, End-to-End Storage Observability (`oprobe.trace/8`)

1. **Cache observability (`FoyerLayer` & hybrid cache):** populate `cache_lookups`, `cache_hits`,
   `cache_hit_bytes`, and `cache_lookup_us`; compute honest `cache_ms` and cache-aware
   `overread_ratio`.
2. **HTTP/2 multiplexing & upload kernel drain:** populate per-connection concurrent `streams_count`,
   `stream_wait_us`, `flow_stall_us`, `send_buffered_us`, and `upload_acked_us`.
3. **`TailCutLayer` cut/hedged attribution:** mark hedged/cut request attempts explicitly in
   `ReqDetail` and waterfall views without polluting `errors` or `reuse_pct`.
4. **Straggler skew & multipart completion tail:** compute concurrent part straggler ratio
   (`max_part_ms / median_part_ms`) and `CompleteMultipartUpload` latency share.
5. **`ListObjects` pagination metrics:** pages per list call, keys per page, and empty/truncated
   page share.
6. **Cross-platform kernel TCP metrics & multi-cloud headers:**
   - Capture socket FDs/handles directly at dial time on Linux, macOS, and Windows, adding
     unprivileged Windows 10+ `WSAIoctl(SIO_TCP_INFO)` support for RTT, min-RTT, cwnd, and
     retransmits.
   - Extract CDN/edge cache status (`x-cache`, `cf-cache-status`, `age`, `x-amz-cf-pop`), storage
     class / S3 Express session headers, KMS encryption markers, S3 XML `SlowDown` vs
     `ServiceUnavailable`, and Azure `x-ms-retry-after-ms`.

## 4. Pillar III — Concise, Zero-Friction CLI Workflows

1. **`oprobe show <A> <B> [...]`:** side-by-side comparison of two or more stored runs or `.oprobe`
   files directly in the terminal (`-o text` and `-o json`), reusing `oprobe-core`'s comparison
   model with zero new subcommands.
2. **Multi-cloud paste-and-run & ambient config discovery:**
   - Recognise Alibaba Cloud OSS, Tencent Cloud COS, Huawei Cloud OBS, Volcengine TOS, Backblaze B2,
     and Cloudflare R2 endpoint/virtual-host URLs automatically.
   - Discover `region` from `~/.aws/config` profiles and `account_name` from
     `AZURE_STORAGE_ACCOUNT_NAME`.
3. **Seamless trace-to-run & proven config save:**
   - Generate workload-aware `oprobe run` reproduction hints (`--existing`, `--preset`, custom
     `--set options.endpoint=...`) on production `.oprobe` files.
   - Add `--save <PATH|OPERATOR>` on `oprobe prove` (and **Save as `op.toml`…** in the app) to write
     proven changes to `op.toml` or `[operators.NAME]` in `config.toml`.

## 5. Pillar IV — Native Desktop & Terminal TUI Polish (`nsh 0.6`)

1. **Stored Proves & Trial Compare:** browse stored proves on each run, inspect verdicts across
   restarts, and jump straight to **Compare A/B Trials** or **Save as `op.toml`…**.
2. **Native desktop details:** `set_scrollbar_theme` overlay scrollbars, horizontal `Compare`
   scrolling, native hover `Tooltip`s with keyboard shortcuts, keyboard `←`/`→`/`Enter` chart
   time-slice selection, single-instance window activation, and multi-file drag-and-drop (`op.toml`,
   `.prove.json`, multiple `.oprobe`s -> `Compare`).
3. **First-class Terminal TUI:** OSC-52 + OS clipboard backend, `nsh-platform-tui` auto-hiding menu
   bar and full shortcut parity, 1-cell resizable sidebar divider, and `80×24` density tuning.
